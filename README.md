# TIME TO DIE 💀

Telegram Mini App по мотивам фильма **«Countdown» (2019)** — того самого, где
приложение показывало, сколько тебе осталось жить. Вводишь имя и дату рождения,
приложение «сканирует» тебя, подключается к Реестру судеб и выдаёт **точную дату
и время смерти** с обратным отсчётом.

Чистый HTML/CSS/JS в одном файле. Без бэкенда, без сети, без зависимостей
(только `telegram-web-app.js` и два Google-шрифта).

> Это развлекательное приложение. Все предсказания вымышлены.

## Как это выглядит

| Этап | Что происходит |
|---|---|
| **Boot** | Чёрный экран, логотип с глитчем, фейковые строки загрузки Реестра |
| **Анкета** | Имя (подтягивается из Telegram) + дата рождения |
| **Соглашение** | Модалка с 11 пунктами «пользовательского соглашения», которые нельзя не принять |
| **Сканирование** | ~8 секунд: вращающиеся кольца, проценты, консольный лог, низкий дрон, сердцебиение, которое ускоряется. На 86% — вспышка и скример |
| **Вердикт** | Дата и время смерти, причина обрыва, живой таймер `дни / часы : минуты : секунды`, шкала прожитой жизни, 10+ карточек статистики, процентиль среди других людей, «особые отметки» |
| **СУБЪЕКТ МЁРТВ** | Отдельный экран со «статикой», если по расчёту дата смерти уже в прошлом |

## Как считается дата

Полностью **детерминированно**: `seed = xmur3("TIME-TO-DIE::registry-of-fates::v1::" + имя + "|" + дата рождения)`
→ `mulberry32(seed)` → все значения. У одного и того же человека всегда одна и
та же дата, поэтому результат можно сверять с друзьями. Имя нормализуется
(регистр и лишние пробелы не влияют).

Распределение возраста смерти (проверено на 10 000 субъектов):

| Возраст | Доля |
|---|---|
| 34–59 | ~10% |
| 60–84 | ~52% |
| 85–96 | ~27% |
| 97–112 | ~8% |
| 113–133 (аномалия) | ~2% |

Медиана — 79 лет. Время смерти смещено к «ведьмину часу» (03:00–05:59).

Результат кэшируется в `localStorage` (ключ `ttd_verdict_v2`) — при повторном
входе появляется ссылка «Открыть его снова».

## Пасхалки

- **13 тапов по таймеру** — скример и сообщение «ТЫ НЕ МОЖЕШЬ ЭТО ИЗМЕНИТЬ»
  (в правом нижнем углу виден счётчик).
- **Редкая причина смерти** — Ожин (демон из фильма), ~3% субъектов.
- **Пункт 11 соглашения** и нижний дисклеймер — единственные честные строки.
- Кнопка **ЗВУК** в шапке вердикта выключает весь звук, если играешь ночью.

## 1. Залить на GitHub Pages

```bash
git add index.html README.md
git commit -m "TIME TO DIE: telegram mini app"
git push
```

Дальше в репозитории: **Settings → Pages → Deploy from a branch → `main`, `/ (root)`**.
Через минуту появится публичный HTTPS-адрес вида
`https://<твой_логин>.github.io/<репозиторий>/` — именно он нужен Telegram.

## 2. Подключить как Telegram Mini App

1. **@BotFather** → `/newbot` (если бота ещё нет).
2. `/newapp` или `/mybots` → бот → **Bot Settings → Menu Button**.
3. В **Web App URL** вставь ссылку с GitHub Pages.
4. `/setmenubutton` — та же ссылка, чтобы приложение открывалось по кнопке меню.
5. Иконку лучше брать тёмную с красным таймером — вписывается в тему.

Приложение само вызывает `ready()`, `expand()`, красит шапку и фон в `#040404`,
использует `HapticFeedback` для вибрации на скримерах и подтягивает имя из
`initDataUnsafe.user`. В обычном браузере всё это аккуратно деградирует.

## 3. Локальный запуск

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Настроить под себя

Всё правится в `<script>` внутри `index.html`:

| Что | Где |
|---|---|
| Причины смерти (~50 шт.) | массив `CAUSES` |
| «Особые отметки» с подстановкой `%Y` `%M` `%D` | массив `WARNINGS` |
| Пункты соглашения | массив `EULA` |
| Строки сканирования | `SCAN_LOGS`, этапы — `SCAN_STAGES` |
| Длительность скана | `var dur = 8200` в `startScan()` |
| Распределение возраста | блок `if(roll < 0.10) …` в `computeVerdict()` |
| Скример на 86% | `if(!scared && prog >= 86)` |
| Палитра | переменные `:root` вверху `<style>` |
| Кэш результатов | `LS_KEY` |

Звук целиком синтезируется через WebAudio (дрон, сердцебиение, колокол,
скример-шум) — никаких внешних файлов. Он стартует только после первого
тапа, как и требуют браузеры.

Анимации уважают `prefers-reduced-motion`: вспышки и скример отключаются,
если у пользователя включён щадящий режим.
